# Planning M2 (Open Shifts, Giving Up Shifts, Notification Delivery) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Employees can claim open shifts and give up shifts (switch or unassign), and every notice Planning has queued since M1 is delivered in-app and by email.

**Architecture:** The new actions are conditional `UPDATE … RETURNING` statements inside the existing `UnitOfWork`, plus a per-employee advisory lock. A delivery sweep turns queued `notification_outbox` rows into `notifications` inbox rows, then sends emails and pushes gateway badge counts. The sweep runs after API responses (Next.js `after()`) and from a daily cron.

**Tech Stack:** As in M1: Next.js 16, React 19, TypeScript strict, Drizzle ORM 0.45 on PostgreSQL 18, Luxon, Vitest 3. One new dependency: `nodemailer`.

**Spec:** [docs/superpowers/specs/2026-10-16-planning-m2-design.md](../specs/2026-10-16-planning-m2-design.md) (decisions D1–D5) and [ListOfRequirements.md](../../../ListOfRequirements.md) v0.4.

**How this plan is written (agreed for efficiency):**
- Every task gives its complete tests. Complete code is given for the risky parts:
  - the claim, switch and unassign transactions (Tasks 2–3);
  - the delivery sweep (Tasks 5–6);
  - the adapters (Task 6);
  - the trigger (Task 7).
- Elsewhere, the code shown is the exact change, and the task names the existing M1 file whose pattern to follow.
- **Execution:**
  - Tasks 1, 2, 3, 5, 6 and 7 each get their own review. Task 1 is reviewed before Task 2 starts, because migration `0001` must not change once applied.
  - Tasks 4 and 8 are reviewed together after Task 8, and Tasks 9–11 together after Task 11.
  - One whole-branch review closes the milestone.
- **Before Task 9:** merge `refactor/planning-ui` into `main` and rebase this branch onto it. Tasks 9–11 mount new components into files that branch is changing, so they describe where the components go instead of quoting exact surrounding lines.

## Global Constraints

- **Naming:** the ERP is **InterlinkERP**. The ERP's former brand name never appears anywhere: code, comments, docs, env vars or commit messages.
- **Commits:** conventional types. No attribution lines (no `Co-Authored-By`, no "Generated with Claude Code"). Work on `feature/m2-open-shifts` in `.worktrees/m2`.
- **Layering:** `src/server/**` never imports React or `src/client/**`. `src/client/**` never imports `src/server/**`. Every query filters `organisation_id`.
- **API contract:**
  - The error envelope is `{"error":{"code","message","correlation_id","details"}}`.
  - POST returns 201, GET and PATCH 200, DELETE 204.
  - Instants are ISO UTC `YYYY-MM-DDTHH:MM:SSZ`.
  - Paths use plural nouns.
- **Version:** `SERVICE_VERSION` becomes `0.2.0` in Task 1 (the first API change of M2). It is not bumped again within M2.
- **DR-02:**
  - The directory may cache the roster email, replaced on every refresh, only to address emails.
  - Notification rows refer to employees by `employee_ref`, never by a stored copy of their email.
  - No other column may store an employee's email.
- **Eligibility (BR-05, v0.4):** the shift has no role or one of the employee's roles, and taking it creates no overlap or time-off conflict. **Public holidays do not count.**
- **Concurrency (NFR-04):**
  - Claims and switch take-overs are conditional updates inside a transaction holding `pg_advisory_xact_lock` for the acting employee.
  - Inside a transaction, eligibility reads go through the transaction's own connection (`scope.eligibility`), never the pool. A transaction that waits on the pool can starve it.
  - Delivery selects with `FOR UPDATE SKIP LOCKED`.
- **DR-02 in error text:** any error message saved to the database has email addresses replaced with `[address]`.
- **Delivery never breaks a request:** the sweep, the mailer and the badge publisher never throw to their caller.
- **New env vars:**
  - `SMTP_URL` (for example `smtps://user:app-password@smtp.gmail.com:465`), `MAIL_FROM`: both optional; without them mail is only logged.
  - `GATEWAY_BADGES` (`on` to enable; anything else is off).

## Review Focus

1. **A person who is both a roster employee and a Planning Manager:** their inbox and badge count must include both their employee notices (by `employee_ref`) and their manager notices (by email) [Task 5 test, Task 6 test].
2. **An employee who left the roster, or has no email in it, still gets notices:** they reach the inbox, and the email is skipped with a recorded reason instead of retrying forever [Task 6 test].
3. **SMTP or the gateway is slow or down:** API responses never wait on delivery, a hung SMTP send gives up after 10 s, and a failed sweep is logged, not thrown [Task 6 and Task 7 tests].
4. **A switch request on a shift that starts while it is pending:** it is no longer offered, a take-over is refused with `SHIFT_STARTED`, and the owner keeps the shift [Task 3 test].
5. **Publishing several open shifts with "notify" on:** each eligible employee gets **one** notice listing all their eligible shifts, not one per shift [Task 8 test].

```ts
import { sql } from 'drizzle-orm';
import type { Db } from '../db/client';
import { HolidayRepository } from '../repo/holidays';
import { Outbox } from '../repo/outbox';
import { ProfileRepository } from '../repo/profiles';
import { SettingsRepository } from '../repo/settings';
import { ShiftRepository } from '../repo/shifts';
import { TimeOffRepository } from '../repo/timeOff';
import { ConflictContext } from './conflictContext';
import { Eligibility } from './eligibility';

/** The repositories a write may use; all of them share one transaction (and one connection). */
export interface WriteScope {
  shifts: ShiftRepository;
  outbox: Outbox;
  settings: SettingsRepository;
  /** BR-05 reading through this transaction's connection, so a transaction never waits on the pool. */
  eligibility: Eligibility;
  /** Serialises this employee's claims and take-overs until the transaction ends (NFR-04). */
  lockEmployee(ref: string): Promise<void>;
}

/**
 * Runs a change and the notifications it causes in one transaction, so either
 * both are saved or neither is. Reused by every shift write.
 */
export class UnitOfWork {
  constructor(private readonly db: Db, private readonly org: string, private readonly defaultTimezone: string) {}

  run<T>(work: (scope: WriteScope) => Promise<T>): Promise<T> {
    return this.db.transaction((tx) => {
      const db = tx as unknown as Db;
      const shifts = new ShiftRepository(db, this.org);
      const profiles = new ProfileRepository(db, this.org);
      const timeOff = new TimeOffRepository(db, this.org);
      const settings = new SettingsRepository(db, this.org, this.defaultTimezone);
      const context = new ConflictContext(shifts, profiles, timeOff, new HolidayRepository(db, this.org), settings);
      return work({
        shifts,
        outbox: new Outbox(db, this.org),
        settings,
        eligibility: new Eligibility(shifts, profiles, timeOff, context),
        lockEmployee: async (ref) => {
          await db.execute(sql`select pg_advisory_xact_lock(hashtext(${`${this.org}:${ref}`}))`);
        },
      });
    });
  }
}
```

`src/server/scheduling/eligibility.ts`:

```ts
import { conflictsForEmployee } from '../domain/conflicts';
import type { ProfileRepository } from '../repo/profiles';
import { factsOf, type ShiftRecord, type ShiftRepository } from '../repo/shifts';
import type { TimeOffRepository } from '../repo/timeOff';
import { ConflictContext } from './conflictContext';

export interface Ineligible {
  rule: 'role' | 'overlap' | 'unavailable';
  message: string;
}

/**
 * BR-05 (v0.4): an employee may take a shift when it has no role or one of their roles, and taking it creates
 * no overlap or time-off conflict. Public holidays do not count: a manager who publishes a holiday shift wants it worked.
 * The role rule is BR-05's own (an employee with no roles cannot take a role shift), so BR-01's role check is not used.
 */
export class Eligibility {
  constructor(
    private readonly shifts: ShiftRepository,
    private readonly profiles: ProfileRepository,
    private readonly timeOff: TimeOffRepository,
    private readonly context: ConflictContext,
  ) {}

  /** Reasons this employee may not take this shift; empty means they may. */
  async check(shift: ShiftRecord, employeeRef: string): Promise<Ineligible[]> {
    const reasons: Ineligible[] = [];
    if (shift.roleId && !(await this.profiles.find(employeeRef)).roleIds.includes(shift.roleId)) {
      reasons.push({ rule: 'role', message: "You do not have this shift's role." });
    }
    for (const conflict of await this.context.conflictsFor({ ...shift, employeeRef }, { holidays: false })) {
      if (conflict.rule !== 'role') reasons.push({ rule: conflict.rule, message: conflict.message });
    }
    return reasons;
  }

  /** The same rule for many employees and shifts at once, from 3 reads. Maps employee_ref to the ids they may take. */
  async eligibleShifts(candidates: ShiftRecord[], refs: string[]): Promise<Map<string, string[]>> {
    const result = new Map<string, string[]>();
    if (candidates.length === 0 || refs.length === 0) return result;
    const from = new Date(Math.min(...candidates.map((s) => s.start.getTime())));
    const to = new Date(Math.max(...candidates.map((s) => s.end.getTime())));
    const [profiles, existing, away] = await Promise.all([this.profiles.all(), this.shifts.overlapping(from, to), this.timeOff.between(from, to)]);
    for (const ref of refs) {
      const roles = profiles.get(ref)?.roleIds ?? [];
      const theirs = existing.filter((s) => s.employeeRef === ref);
      const spans = ConflictContext.spans(away.filter((t) => t.employeeRef === ref), [], 'UTC'); // no holidays, so the zone is unused
      const fits: string[] = [];
      for (const shift of candidates) {
        if (shift.roleId && !roles.includes(shift.roleId)) continue;
        const candidate = { ...shift, employeeRef: ref };
        const facts = [...theirs.filter((s) => s.id !== shift.id).map(factsOf), factsOf(candidate)];
        if ((conflictsForEmployee(facts, spans, []).get(shift.id) ?? []).length === 0) fits.push(shift.id);
      }
      if (fits.length > 0) result.set(ref, fits);
    }
    return result;
  }
}
```

`check` and `eligibleShifts` apply the same rule. `check` also returns the reasons a refusal needs, and `eligibleShifts` is for lists.

```ts
import type { Principal } from '../auth/principal';
import { HttpError } from '../http/errors';
import { Input } from '../http/input';
import type { DirectoryRepository } from '../repo/directory';
import type { ProfileRepository } from '../repo/profiles';
import type { RoleRepository } from '../repo/roles';
import type { SettingsRepository } from '../repo/settings';
import { type ShiftRecord, type ShiftRepository, shiftToMyApi } from '../repo/shifts';
import type { Clock } from '../support/clock';
import { localMidnight, nextDay } from '../support/time';
import type { Eligibility } from './eligibility';
import { MAX_RANGE_DAYS } from './scheduleService';
import type { UnitOfWork } from './unitOfWork';

export const taken = () => HttpError.conflict('SHIFT_TAKEN', 'Someone else took this shift first.');
export const started = () => HttpError.conflict('SHIFT_STARTED', 'This shift has already started.');

/** Only people on the roster plan their own shifts. */
export function rosterRef(by: Principal): string {
  if (!by.employeeRef) throw HttpError.forbidden('You are not on the planning roster.', 'NOT_ON_ROSTER');
  return by.employeeRef;
}

export function shiftIdFrom(body: Record<string, unknown>): string {
  const input = new Input(body);
  const id = input.string('shift_id', 36, true);
  input.check();
  return id!;
}

/** FR-OPN-01..05, BR-05..07, NFR-04: what employees do with open shifts and with shifts they cannot work. */
export class OpenShiftService {
  constructor(
    private readonly shifts: ShiftRepository,
    private readonly profiles: ProfileRepository,
    private readonly roles: RoleRepository,
    private readonly directory: DirectoryRepository,
    private readonly settings: SettingsRepository,
    private readonly eligibility: Eligibility,
    private readonly unit: UnitOfWork,
    private readonly clock: Clock,
  ) {}

  async available(query: Record<string, string>, by: Principal) {
    const ref = rosterRef(by);
    const input = new Input(query);
    const range = input.dateRange('from', 'to', MAX_RANGE_DAYS);
    input.check();
    const settings = await this.settings.get();
    const zone = (await this.profiles.find(ref)).timezone ?? settings.timezone;
    const from = new Date(localMidnight(range![0], zone));
    const to = new Date(localMidnight(nextDay(range![1]), zone));
    const now = this.clock.now();
    const [open, switchable, roles, people] = await Promise.all([
      this.shifts.openPublished(from, to, now), this.shifts.upForSwitch(from, to, now), this.roles.all(), this.directory.all(),
    ]);
    const names = new Map(people.map((p) => [p.employeeRef, p.displayName]));
    // Switch requests only count in Switch mode, so one that slipped past a mode change is never offered.
    const takeable = settings.give_up_mode === 'switch' ? switchable.filter((s) => s.employeeRef !== ref) : [];
    const allowed = new Set((await this.eligibility.eligibleShifts([...open, ...takeable], [ref])).get(ref) ?? []);
    return {
      timezone: zone, from: range![0], to: range![1],
      give_up: { mode: settings.give_up_mode, window_days: settings.unassign_window_days },
      roles,
      open: open.filter((s) => allowed.has(s.id)).map(shiftToMyApi),
      up_for_switch: takeable.filter((s) => allowed.has(s.id)).map((s) => ({
        ...shiftToMyApi(s), owner_ref: s.employeeRef, owner_name: names.get(s.employeeRef!) ?? 'Unknown employee',
      })),
    };
  }

  /** FR-OPN-02. The lock makes one employee's claims run one at a time; the conditional update makes the shift go to exactly one person. */
  async claim(body: Record<string, unknown>, by: Principal): Promise<ShiftRecord> {
    const ref = rosterRef(by);
    const id = shiftIdFrom(body);
    const now = this.clock.now();
    const shift = await this.shifts.find(id);
    if (!shift || shift.state !== 'published') throw HttpError.notFound('No published shift with that id.');
    if (shift.start <= now) throw started();
    if (shift.employeeRef) throw taken();
    return this.unit.run(async (scope) => {
      await scope.lockEmployee(ref);
      await requireEligible(scope.eligibility, shift, ref);
      const claimed = (await scope.shifts.claim(shift.id, ref, now)) ?? (() => { throw taken(); })();
      await scope.outbox.addForManagers('shift_claimed', shift.id, { shift_id: shift.id, employee_ref: ref }, now);
      return claimed;
    });
  }
}

/** Refuses with every reason (FR-OPN-02 AC2). Pass `scope.eligibility` inside a transaction. */
export async function requireEligible(eligibility: Eligibility, shift: ShiftRecord, ref: string): Promise<void> {
  const reasons = await eligibility.check(shift, ref);
  if (reasons.length > 0) throw HttpError.conflict('NOT_ELIGIBLE', 'You cannot take this shift.', { reasons });
}
```

`requireEligible` runs after the advisory lock, on the transaction's own connection. Under READ COMMITTED each statement sees data committed before it started. A second claim by the same employee therefore waits on the lock until the first commits, and then sees its result.

```ts
  async takeOver(body: Record<string, unknown>, by: Principal): Promise<ShiftRecord> {
    const ref = rosterRef(by);
    const now = this.clock.now();
    const shift = await this.shifts.find(shiftIdFrom(body));
    if (!shift || shift.state !== 'published') throw HttpError.notFound('No published shift with that id.');
    if (shift.employeeRef === ref) throw HttpError.conflict('OWN_SHIFT', 'This is already your shift.');
    if (shift.start <= now) throw started();
    // Checked before the request itself: a request that slipped past a change to Unassign is never acted on (BR-07).
    if ((await this.settings.get()).give_up_mode !== 'switch') throw modeOff('switch');
    if (!shift.switchRequestedAt || !shift.employeeRef) throw notUp();
    const owner = shift.employeeRef;
    return this.unit.run(async (scope) => {
      await scope.lockEmployee(ref);
      await requireEligible(scope.eligibility, shift, ref);
      const row = (await scope.shifts.takeOver(shift.id, owner, ref, now)) ?? (() => { throw taken(); })();
      await scope.outbox.add('switch_taken', owner, shift.id, { shift_id: shift.id, taker_ref: ref }, now, now);
      await scope.outbox.add('shift_assigned', ref, shift.id, { shift_id: shift.id }, now, now);
      await scope.outbox.addForManagers('shift_switched', shift.id, { shift_id: shift.id, from_ref: owner, to_ref: ref }, now);
      return row;
    });
  }

  /** FR-OPN-04, BR-06: the shift becomes an open shift and stays published. */
  async unassign(body: Record<string, unknown>, by: Principal): Promise<ShiftRecord> {
    const ref = rosterRef(by);
    const shift = await this.ownPublished(shiftIdFrom(body), ref);
    const now = this.clock.now();
    if (shift.start <= now) throw started();
    const settings = await this.settings.get();
    if (settings.give_up_mode !== 'unassign') throw modeOff('unassign');
    const earliest = new Date(now.getTime() + settings.unassign_window_days * 86_400_000);
    if (shift.start <= earliest) {
      throw HttpError.conflict('OUTSIDE_UNASSIGN_WINDOW', `Shifts can only be given up more than ${settings.unassign_window_days} days before they start.`);
    }
    return this.unit.run(async (scope) => {
      const row = (await scope.shifts.unassign(shift.id, ref, earliest, now)) ?? (() => { throw changed(); })();
      await scope.outbox.addForManagers('shift_given_up', shift.id, { shift_id: shift.id, employee_ref: ref }, now);
      return row;
    });
  }
```

```ts
import { DateTime } from 'luxon';
import type { ShiftRecord } from '../repo/shifts';

export interface Message {
  title: string;
  body: string;
  link: string;
}

export interface RenderContext {
  /** Every shift the notice mentions, deleted ones included. */
  shifts: Map<string, ShiftRecord>;
  /** employee_ref -> display name */
  names: Map<string, string>;
  /** The recipient's time zone. */
  zone: string;
  publicUrl: string;
}

/** DR-02: error text saved to the database never keeps an email address (SMTP errors often quote the recipient). */
export function scrubAddresses(text: string): string {
  return text.replace(/[^\s@<>"'(),;:]+@[^\s@<>"'(),;:]+/g, '[address]').slice(0, 500);
}

export function shiftIdsOf(payload: Record<string, unknown>): string[] {
  if (Array.isArray(payload.shift_ids)) return payload.shift_ids.filter((id): id is string => typeof id === 'string');
  return typeof payload.shift_id === 'string' ? [payload.shift_id] : [];
}

/**
 * "Wed 14 Oct, 09:00–17:00" in `zone`; the end date is shown only when it falls on another day.
 * The locale is pinned to English so emails and tests never depend on the server's default language.
 */
export function formatSpan(start: Date, end: Date, zone: string): string {
  const s = DateTime.fromJSDate(start, { zone }).setLocale('en');
  const e = DateTime.fromJSDate(end, { zone }).setLocale('en');
  const day = s.toFormat('ccc d LLL');
  return s.hasSame(e, 'day') ? `${day}, ${s.toFormat('HH:mm')}–${e.toFormat('HH:mm')}` : `${day}, ${s.toFormat('HH:mm')} – ${e.toFormat('ccc d LLL, HH:mm')}`;
}

/** One place for every notice's wording (FR-NTF-01..03). Throws on an unknown kind or a missing shift; the sweep retries. */
export function render(kind: string, payload: Record<string, unknown>, ctx: RenderContext): Message {
  const span = (id: string) => {
    const shift = ctx.shifts.get(id);
    if (!shift) throw new Error(`Shift ${id} not found`);
    return formatSpan(shift.start, shift.end, ctx.zone);
  };
  const name = (ref: unknown) => (typeof ref === 'string' && ctx.names.get(ref)) || 'Someone';
  const ids = shiftIdsOf(payload);
  const first = () => span(ids[0] ?? '');
  const my = `${ctx.publicUrl}/my`;
  const board = `${ctx.publicUrl}/schedule`;
  switch (kind) {
    case 'schedule_published':
      return { title: ids.length === 1 ? 'Your shift was published' : `Your ${ids.length} shifts were published`, body: ids.map(span).join('\n'), link: my };
    case 'shift_assigned':
      return { title: 'You have a new shift', body: first(), link: my };
    case 'shift_unassigned':
      return { title: 'A shift is no longer yours', body: first(), link: my };
    case 'shift_changed':
      return { title: 'One of your shifts changed', body: `${first()}. Changed: ${(Array.isArray(payload.changed) ? payload.changed : []).join(', ')}.`, link: my };
    case 'shift_deleted':
      return { title: 'A shift was cancelled', body: formatSpan(new Date(String(payload.start_at)), new Date(String(payload.end_at)), ctx.zone), link: my };
    case 'switch_taken':
      return { title: 'Your shift was taken', body: `${name(payload.taker_ref)} took your shift on ${first()}.`, link: my };
    case 'switch_cancelled':
      return { title: 'Your switch request was cancelled', body: `Shifts can no longer be put up for switch, so your request for ${first()} was cancelled. The shift is still yours.`, link: my };
    case 'open_shifts_available':
      return { title: ids.length === 1 ? 'An open shift you can take' : `${ids.length} open shifts you can take`, body: ids.map(span).join('\n'), link: my };
    case 'shift_claimed':
      return { title: 'Open shift claimed', body: `${name(payload.employee_ref)} claimed the open shift on ${first()}.`, link: board };
    case 'shift_switched':
      return { title: 'Shift switched', body: `${name(payload.to_ref)} took over ${name(payload.from_ref)}'s shift on ${first()}.`, link: board };
    case 'shift_given_up':
      return { title: 'Shift given up', body: `${name(payload.employee_ref)} gave up the shift on ${first()}. It is now an open shift.`, link: board };
    default:
      throw new Error(`Unknown notification kind ${kind}`);
  }
}
```

```ts
import { and, count, desc, eq, inArray, isNull, lt, or, type SQL, sql } from 'drizzle-orm';
import type { Principal } from '../auth/principal';
import type { Db } from '../db/client';
import { notifications } from '../db/schema';
import { iso } from '../support/time';

/** A signed-in person's inbox address: their employee_ref and their email (DR-02). */
export interface Recipient {
  ref: string | null;
  email: string | null;
}

export const recipientOf = (p: Principal): Recipient => ({ ref: p.employeeRef, email: p.email ? p.email.trim().toLowerCase() : null });

export function notificationToApi(n: typeof notifications.$inferSelect) {
  return { id: n.id, kind: n.kind, title: n.title, body: n.body, link: n.link, shift_id: n.shiftId, created_at: iso(n.createdAt), read_at: n.readAt ? iso(n.readAt) : null };
}

export class NotificationRepository {
  constructor(private readonly db: Db, private readonly org: string) {}

  private mine(who: Recipient): SQL {
    const parts: SQL[] = [];
    if (who.ref) parts.push(eq(notifications.recipientRef, who.ref));
    if (who.email) parts.push(eq(notifications.recipientEmail, who.email));
    return and(eq(notifications.organisationId, this.org), parts.length > 0 ? or(...parts) : sql`false`)!;
  }

  async list(who: Recipient, unreadOnly: boolean, before: number | null, limit = 50) {
    const rows = await this.db.select().from(notifications)
      .where(and(this.mine(who), unreadOnly ? isNull(notifications.readAt) : undefined, before !== null ? lt(notifications.id, before) : undefined))
      .orderBy(desc(notifications.id)).limit(limit);
    return rows.map(notificationToApi);
  }

  async unreadCount(who: Recipient): Promise<number> {
    const [row] = await this.db.select({ n: count() }).from(notifications).where(and(this.mine(who), isNull(notifications.readAt)));
    return Number(row?.n ?? 0);
  }

  /** ids = null marks everything. Only the person's own unread rows change. */
  async markRead(who: Recipient, ids: number[] | null, now: Date): Promise<number> {
    if (ids !== null && ids.length === 0) return 0;
    const rows = await this.db.update(notifications).set({ readAt: now })
      .where(and(this.mine(who), isNull(notifications.readAt), ids ? inArray(notifications.id, ids) : undefined))
      .returning({ id: notifications.id });
    return rows.length;
  }
}
```

```ts
import { and, eq, isNull, lte } from 'drizzle-orm';
import type { Db } from '../db/client';
import { notificationOutbox, notifications } from '../db/schema';
import type { Logger } from '../http/kernel';
import type { DirectoryRepository } from '../repo/directory';
import type { ManagerRepository } from '../repo/managers';
import type { ProfileRepository } from '../repo/profiles';
import type { SettingsRepository } from '../repo/settings';
import type { ShiftRepository } from '../repo/shifts';
import type { Clock } from '../support/clock';
import { render, scrubAddresses, shiftIdsOf } from './messages';

export const MAX_OUTBOX_ATTEMPTS = 5;
const BATCH = 100;

/** Who a sweep wrote to, so their badge counts can be refreshed. */
export interface Touched {
  refs: Set<string>;
  emails: Set<string>;
}

export interface DeliveryReport {
  notified: number;
}

export interface DeliveryDeps {
  db: Db;
  org: string;
  shifts: ShiftRepository;
  directory: DirectoryRepository;
  profiles: ProfileRepository;
  managers: ManagerRepository;
  settings: SettingsRepository;
  clock: Clock;
  log: Logger;
  /** Read only when there is something to render, so building the service never needs PUBLIC_URL. */
  publicUrl: () => string;
}

/** FR-NTF-01..04: turns queued notices into inbox rows (and, from Task 6, emails and badges). */
export class DeliveryService {
  constructor(private readonly d: DeliveryDeps) {}

  /** Step 1. Overlapping sweeps skip each other's rows (SKIP LOCKED), so nothing is delivered twice. */
  async expandDue(): Promise<Touched> {
    const { db, org, clock } = this.d;
    const now = clock.now();
    const touched: Touched = { refs: new Set(), emails: new Set() };
    await db.transaction(async (tx) => {
      const rows = await tx.select().from(notificationOutbox)
        .where(and(eq(notificationOutbox.organisationId, org), isNull(notificationOutbox.deliveredAt), isNull(notificationOutbox.cancelledAt), lte(notificationOutbox.deliverAfter, now)))
        .orderBy(notificationOutbox.id).limit(BATCH).for('update', { skipLocked: true });
      if (rows.length === 0) return;
      const [shifts, directory, profiles, managers, orgZone] = await Promise.all([
        this.d.shifts.byIds([...new Set(rows.flatMap((r) => shiftIdsOf(r.payload)))]),
        this.d.directory.all(), this.d.profiles.all(), this.d.managers.all(), this.d.settings.timezone(),
      ]);
      const base = { shifts: new Map(shifts.map((s) => [s.id, s])), names: new Map(directory.map((e) => [e.employeeRef, e.displayName])), publicUrl: this.d.publicUrl() };
      for (const row of rows) {
        let inbox: (typeof notifications.$inferInsert)[];
        try {
          const recipients = row.audience === 'managers'
            ? managers.map((m) => ({ ref: null, email: m.email, zone: orgZone }))
            : row.employeeRef ? [{ ref: row.employeeRef, email: null, zone: profiles.get(row.employeeRef)?.timezone ?? orgZone }] : [];
          const ids = shiftIdsOf(row.payload);
          inbox = recipients.map((r) => ({
            organisationId: org, recipientRef: r.ref, recipientEmail: r.email, kind: row.kind, ...render(row.kind, row.payload, { ...base, zone: r.zone }),
            shiftId: ids.length === 1 ? ids[0]! : null, outboxId: row.id, createdAt: now, emailNextAt: now,
          }));
        } catch (error) {
          const attempts = row.attempts + 1;
          await tx.update(notificationOutbox).set({ attempts, lastError: scrubAddresses(String(error)), deliveredAt: attempts >= MAX_OUTBOX_ATTEMPTS ? now : null })
            .where(and(eq(notificationOutbox.organisationId, org), eq(notificationOutbox.id, row.id)));
          this.d.log(`[delivery] notice ${row.id} (${row.kind}) failed: ${String(error)}`);
          continue;
        }
        if (inbox.length > 0) await tx.insert(notifications).values(inbox);
        await tx.update(notificationOutbox).set({ deliveredAt: now }).where(and(eq(notificationOutbox.organisationId, org), eq(notificationOutbox.id, row.id)));
        for (const r of inbox) {
          if (r.recipientRef) touched.refs.add(r.recipientRef);
          if (r.recipientEmail) touched.emails.add(r.recipientEmail);
        }
      }
    });
    return touched;
  }

  /** The whole sweep. Never throws: delivery must not break the request that triggered it. */
  async deliverDue(): Promise<DeliveryReport> {
    try {
      const touched = await this.expandDue();
      return { notified: touched.refs.size + touched.emails.size };
    } catch (error) {
      this.d.log(`[delivery] sweep failed: ${error instanceof Error ? error.message : String(error)}`);
      return { notified: 0 };
    }
  }
}
```

```ts
import nodemailer, { type Transporter } from 'nodemailer';
import type { Logger } from '../http/kernel';

export interface MailMessage {
  to: string;
  subject: string;
  text: string;
}

export type SendResult = { ok: true } | { ok: false; error: string };

/** FR-NTF-04 email. Never throws; a failure is a result the sweep retries. */
export interface Mailer {
  send(message: MailMessage): Promise<SendResult>;
}

export async function withTimeout(work: Promise<unknown>, ms: number): Promise<SendResult> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<SendResult>((resolve) => {
    timer = setTimeout(() => resolve({ ok: false, error: `Timed out after ${ms} ms.` }), ms);
  });
  const sent = work.then((): SendResult => ({ ok: true }), (error: unknown): SendResult => ({ ok: false, error: error instanceof Error ? error.message : String(error) }));
  return Promise.race([sent, timeout]).finally(() => clearTimeout(timer));
}

/** D2: any SMTP provider, e.g. smtps://user:app-password@smtp.gmail.com:465. */
export class SmtpMailer implements Mailer {
  private readonly transport: Transporter;

  constructor(url: string, private readonly from: string, private readonly timeoutMs = 10_000) {
    this.transport = nodemailer.createTransport(url);
  }

  send(message: MailMessage): Promise<SendResult> {
    return withTimeout(this.transport.sendMail({ from: this.from, to: message.to, subject: message.subject, text: message.text }), this.timeoutMs);
  }
}

/** Used when SMTP_URL or MAIL_FROM is unset, so local development needs nothing. */
export class LogMailer implements Mailer {
  constructor(private readonly log: Logger) {}

  async send(message: MailMessage): Promise<SendResult> {
    this.log(`[mail] not configured; would send "${message.subject}" to one recipient`);
    return { ok: true };
  }
}
```

```ts
  readonly enabled = true;

  constructor(
    private readonly http: HttpClient,
    private readonly gatewayUrl: string,
    private readonly serviceId: string,
    private readonly clientId: string,
    private readonly clientSecret: string,
    private readonly log: Logger,

  async publish(badges: BadgeCount[]): Promise<boolean> {

      const chunk = badges.slice(i, i + 500).map((b) => ({ email: b.email.trim().toLowerCase(), count: Math.max(0, Math.min(99_999, Math.trunc(b.count))) }));

        timeoutMs: 5_000,
      });

        ok = false;
        this.log(`[badges] the gateway did not accept badge counts (${result.networkError ? 'unreachable' : `HTTP ${result.status}`})`);
```

```ts
  private pending: Touched = { refs: new Set(), emails: new Set() };

  constructor(
    private readonly delivery: { deliverDue(): Promise<unknown>; pushBadges(touched: Touched): Promise<void> },
    private readonly clock: Clock,
    private readonly log: Logger,
    private readonly minGapMs = MIN_GAP_MS,
  ) {}

  noteBadges(touched: Touched): void {
    for (const ref of touched.refs) this.pending.refs.add(ref);
    for (const email of touched.emails) this.pending.emails.add(email);
  }

  kick(): Promise<void> {
    return Promise.all([this.flushBadges(), this.sweep()]).then(() => undefined);
  }

  private flushBadges(): Promise<void> {
    if (this.pending.refs.size === 0 && this.pending.emails.size === 0) return Promise.resolve();
    const touched = this.pending;
    this.pending = { refs: new Set(), emails: new Set() };
    return this.delivery.pushBadges(touched).catch((error: unknown) => this.log(`[badges] push failed: ${message(error)}`));
  }

  private sweep(): Promise<void> {
    if (this.running) return this.running;
    const now = this.clock.now().getTime();
    if (now - this.lastStart < this.minGapMs) return Promise.resolve();
    this.lastStart = now;
    this.running = this.delivery.deliverDue()
      .then(() => undefined, (error: unknown) => this.log(`[delivery] trigger failed: ${message(error)}`))
      .finally(() => {
        this.running = null;
      });
    return this.running;
  }
}
```

```ts
import { Input } from '../http/input';
import type { DirectoryRepository } from '../repo/directory';
import type { Clock } from '../support/clock';
import type { UnitOfWork } from './unitOfWork';

/** FR-PUB-01, FR-PUB-03, FR-NTF-01. Publishing and its notices are saved in one transaction. */
export class PublishService {
  constructor(
    private readonly unit: UnitOfWork,
    private readonly clock: Clock,
    private readonly directory: DirectoryRepository,
  ) {}

  async publish(body: Record<string, unknown>): Promise<{ published: number; employees_notified: number; open_shift_notices: number }> {
    const input = new Input(body);
    const ids = input.stringList('shift_ids', 1000, true);
    if (ids && ids.length === 0) input.error('shift_ids', 'List at least one shift.');
    const notifyOpen = input.has('notify_open_shifts') ? input.raw('notify_open_shifts') : false;
    if (typeof notifyOpen !== 'boolean') input.error('notify_open_shifts', 'Must be true or false.');
    input.check();

    const now = this.clock.now();
    // Read before the transaction, so the transaction never waits on the pool.
    const people = notifyOpen === true ? (await this.directory.all()).map((p) => p.employeeRef) : [];
    return this.unit.run(async (scope) => {
      const published = await scope.shifts.publish(ids!, now);
      const byEmployee = new Map<string, string[]>();
      for (const shift of published) {
        if (!shift.employeeRef) continue;
        if (!byEmployee.has(shift.employeeRef)) byEmployee.set(shift.employeeRef, []);
        byEmployee.get(shift.employeeRef)!.push(shift.id);
      }
      for (const [ref, shiftIds] of byEmployee) await scope.outbox.add('schedule_published', ref, null, { shift_ids: shiftIds }, now, now);

      // FR-PUB-03: one notice per eligible employee, listing every open shift they may take. Three bulk reads, on this transaction.
      const open = published.filter((s) => !s.employeeRef && s.start > now);
      const eligible = notifyOpen === true ? await scope.eligibility.eligibleShifts(open, people) : new Map<string, string[]>();
      for (const [ref, shiftIds] of eligible) await scope.outbox.add('open_shifts_available', ref, null, { shift_ids: shiftIds }, now, now);
      const openNotices = eligible.size;
      return { published: published.length, employees_notified: byEmployee.size, open_shift_notices: openNotices };
    });
  }
}
```

```tsx
import { useCallback, useEffect, useState } from 'react';
import { api } from '../api';

const POLL_MS = 60_000;

/** FR-NTF-04 in-app: a bell with the unread count and a panel of recent notices. Failing to load never breaks the page. */
export function NotificationBell() {
  const [data, setData] = useState<NotificationsPayload | null>(null);
  const [open, setOpen] = useState(false);

  const load = useCallback(async () => {
    try {
      setData(await api<NotificationsPayload>('GET', '/api/notifications'));
    } catch {
      // The bell is a nicety; a 401 already reloads the page through api().
    }
  }, []);

  useEffect(() => {
    void load();
    const timer = window.setInterval(() => {
      if (document.visibilityState === 'visible') void load();
    }, POLL_MS);
    return () => window.clearInterval(timer);
  }, [load]);

  useEffect(() => {
    if (!open) return;
    const close = (e: KeyboardEvent) => {
      if (e.key === 'Escape') setOpen(false);
    };
    window.addEventListener('keydown', close);
    return () => window.removeEventListener('keydown', close);
  }, [open]);

  async function markRead(body: { ids: number[] } | { all: true }) {
    try {
      await api('POST', '/api/notification-reads', body);
    } finally {
      await load();
    }
  }

  async function openItem(item: NotificationItem) {
    if (!item.read_at) await markRead({ ids: [item.id] });
    window.location.assign(item.link);
  }

  const unread = data?.unread_count ?? 0;
  return (
    <div className="bell">
      <button type="button" className="bell-button" aria-label={unread > 0 ? `Notifications, ${unread} unread` : 'Notifications'} aria-expanded={open} onClick={() => setOpen(!open)}>

        {unread > 0 && <span className="bell-count" aria-hidden="true">{unreadLabel(unread)}</span>}
      </button>
      {open && (
        <div className="bell-panel" role="dialog" aria-label="Notifications">
          <div className="bell-head">
            <strong>Notifications</strong>
            {unread > 0 && <button type="button" onClick={() => void markRead({ all: true })}>Mark all read</button>}
          </div>
          {data && data.notifications.length === 0 && <p className="muted">Nothing yet.</p>}
          <ul>
            {data?.notifications.map((n) => (
              <li key={n.id} className={n.read_at ? 'read' : 'unread'}>
                <button type="button" onClick={() => void openItem(n)}>
                  <strong>{n.title}</strong>
                  <span className="bell-body">{n.body}</span>
                </button>
              </li>
            ))}
          </ul>
        </div>
      )}
```

```ts
'use client';

import { useCallback, useEffect, useState } from 'react';
import { api, ApiError, query } from '../api';
import type { GiveUp, MyShift, OpenShiftsPayload } from '../types';

export type GiveUpAction = { kind: 'switch' } | { kind: 'cancel-switch' } | { kind: 'unassign' } | { kind: 'none'; reason: string };

/** Which give-up control one of my published shifts gets (FR-OPN-03..05, BR-06, BR-07). The server re-checks all of it. */
export function giveUpAction(shift: MyShift, giveUp: GiveUp, now: Date): GiveUpAction {
  const start = Date.parse(shift.start_at);
  if (start <= now.getTime()) return { kind: 'none', reason: 'Already started.' };
  if (giveUp.mode === 'switch') return shift.switch_requested ? { kind: 'cancel-switch' } : { kind: 'switch' };
  if (start <= now.getTime() + giveUp.window_days * 86_400_000) return { kind: 'none', reason: `Can only be given up more than ${giveUp.window_days} days ahead.` };
  return { kind: 'unassign' };
}

/** A refusal as one sentence, with eligibility reasons when the server sent them. Never shows raw browser errors. */
export function problemText(error: unknown): string {
  if (!(error instanceof ApiError)) return 'Something went wrong. Please try again.';
  const reasons = (error.details as { reasons?: { message: string }[] } | null)?.reasons ?? [];
  return [error.message, ...reasons.map((r) => r.message)].join(' ');
}

/** Loads available shifts for a date range; reload after any action. */
export function useOpenShifts(from: string, to: string) {
  const [data, setData] = useState<OpenShiftsPayload | null>(null);
  const reload = useCallback(async () => {
    try {
      setData(await api<OpenShiftsPayload>('GET', `/api/my/open-shifts${query({ from, to })}`));
    } catch {
      setData(null);
    }
  }, [from, to]);
  useEffect(() => void reload(), [reload]);
  return { data, reload };
}
```

```tsx
function when(shift: MyShift, zone: string): string {
  return `${isoToWall(shift.start_at, zone).date} ${formatTime(shift.start_at, zone)}–${formatTime(shift.end_at, zone)}`;
}

/** FR-OPN-01..03: open shifts I can claim and colleagues' shifts I can take. */
export function AvailableShifts({ data, onChanged }: { data: OpenShiftsPayload | null; onChanged: () => Promise<void> }) {
  const { toast } = useFeedback();
  const [busy, setBusy] = useState<string | null>(null);
  if (!data || (data.open.length === 0 && data.up_for_switch.length === 0)) return null;

  async function act(id: string, path: string, done: string) {
    if (busy) return;
    setBusy(id);
    try {
      await api('POST', path, { shift_id: id });
      toast(done);
    } catch (error) {
      toast(problemText(error), undefined, 6000);
    } finally {
      setBusy(null);
      await onChanged();
    }
  }

  return (
    <section className="available" aria-labelledby="available-heading">
      <h2 id="available-heading">Available shifts</h2>
      <ul>
        {data.open.map((s) => (
          <li key={s.id}>
            <span>{when(s, data.timezone)} · open shift</span>
            <button type="button" disabled={busy !== null} onClick={() => void act(s.id, '/api/shift-claims', 'Shift claimed.')}>Claim</button>
          </li>
        ))}
        {data.up_for_switch.map((s) => (
          <li key={s.id}>
            <span>{when(s, data.timezone)} · {s.owner_name} needs cover</span>
```

```tsx
'use client';

import { useState } from 'react';
import { api } from '../api';
import { useFeedback } from '../feedback';
import type { GiveUp, MyShift } from '../types';
import { giveUpAction, problemText } from './openShifts';

/** FR-OPN-03/04: the one give-up control a shift of mine gets under the active mode. */
export function GiveUpButton({ shift, giveUp, onChanged }: { shift: MyShift; giveUp: GiveUp; onChanged: () => Promise<void> }) {
  const { confirm, toast } = useFeedback();
  const [busy, setBusy] = useState(false);
  const action = giveUpAction(shift, giveUp, new Date());
  if (action.kind === 'none') return null;

  const labels = {
    switch: ['Ask for cover', 'Put this shift up for switch?', ['It stays yours until a colleague takes it.'], 'Shift is up for switch.'],
    'cancel-switch': ['Keep shift', 'Withdraw your switch request?', ['The shift stays yours.'], 'Switch request withdrawn.'],
    unassign: ['Give up', 'Give up this shift?', ['It becomes an open shift that colleagues can claim.'], 'Shift given up.'],
  } as const;
  const [label, title, lines, done] = labels[action.kind];

  async function run() {
    if (busy || !(await confirm(title, [...lines], label))) return;
    setBusy(true);
    try {
      if (action.kind === 'cancel-switch') await api('DELETE', `/api/switch-requests/${shift.id}`);
      else await api('POST', action.kind === 'switch' ? '/api/switch-requests' : '/api/unassignments', { shift_id: shift.id });
      toast(done);
    } catch (error) {
      toast(problemText(error), undefined, 6000);
    } finally {
      setBusy(false);
      await onChanged();
    }
  }

  return <button type="button" className="give-up" disabled={busy} onClick={() => void run()}>{label}</button>;
}
```
